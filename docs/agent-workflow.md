# Agent Workflow

1. Retrieve issue/requirement.
2. Inspect repository metadata/tree.
3. Run keyword and semantic retrieval.
4. Build a bounded context window.
5. Analyze root cause with confidence/uncertainty.
6. Produce an implementation plan.
7. Generate a patch.
8. Apply scope and secret safety checks.
9. Generate/run tests.
10. Analyze failures and retry at most three times.
11. Present diff and request human approval.
12. Create isolated branch, commit, and pull request.
13. Record every significant action in the audit trail.
